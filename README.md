## How this repository works

The daily workflow:

1. Reads recent items from an approved set of first-party research and engineering feeds.
2. Removes sources that have already been used.
3. Ranks the remaining items for recency, credibility and relevance to the day's topic.
4. Produces a short, human-readable brief using a controlled writing prompt.
5. Rejects unsupported personal claims, missing citations, duplicates and malformed output.
6. Adds one dated Markdown file and refreshes this index in a single commit.

The workflow runs at 07:17 in the `Europe/London` time zone. A second run at 18:43 acts as a recovery check and exits without a commit when that day's brief already exists.

## Transparency

The briefs are automatically curated from the cited sources. Automation never claims that I personally tested, built or deployed the featured technology. Completed personal projects are maintained separately in their own repositories.
